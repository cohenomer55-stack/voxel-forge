# VoxelForge Free

גרסה חינמית לחלוטין של מחולל Litematica: אין OpenAI API, אין API key, ואין חיוב AI.

האתר עדיין מקבל תיאור טבעי, בונה עולם ווקסלי, מייצר PNG ומאפשר להוריד `.litematic`.
ההבדל הוא שהתכנון נעשה מקומית באמצעות מתכנן מבוסס מילות מפתח/מידות במקום מודל ענן. לכן התיאורים החופשיים פחות עשירים ממודל שפה מלא, אבל השירות עובד בלי קרדיטים ל־OpenAI.

## Render

אפשר להשאיר את השירות הקיים ב־Render ולדחוף את הקבצים החדשים ל־GitHub. אין צורך ב־`OPENAI_API_KEY` יותר.

ב־Render אפשר למחוק את משתנה הסביבה `OPENAI_API_KEY`, או להשאירו — הקוד החדש לא משתמש בו.
